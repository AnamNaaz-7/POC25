# Terraform AWS Infrastructure POC

## 📌 Objective
This project demonstrates Infrastructure as Code (IaC) using Terraform to provision AWS resources.

## 🚀 Resources Created
- VPC
- Subnet
- Internet Gateway
- Route Table
- Security Group
- EC2 Instance
- S3 Bucket

## 🛠 Tools Used
- Terraform
- AWS EC2, S3, VPC
- AWS CodeBuild (for automation)

## ⚙️ Commands

```bash
terraform init
terraform plan
terraform apply
